R简介

R 是一种强大的编程语言，常用于数据分析、图形绘制，尤其擅长统计分析。R 可以在 www.r-project.org 免费获取，并为 Linux、macOS 和 Windows 提供易于安装的二进制版本。本 notebook 面向学生和研究人员，介绍 R 的基础用法。学习本节不需要事先具备 R 经验；如果你熟悉 Bash、Matlab 或 Python 等脚本语言，会更容易上手。
进行 R 编程时，最推荐的方式是安装 RStudio 或 Visual Studio Code。在这里，我们会学习 R 的一些基础知识，以及如何加载和处理数据。


简要介绍

刚开始学习 R（或任何编程语言）时，我们需要掌握三项基本能力：

  • 1. 阅读代码： 最开始，你会接触到别人已经写好的代码。阅读代码是熟悉程序逻辑、命令以及 R 如何“表达”的第一步。 示例：理解 mean(c(1, 2, 3)) 的含义。
  • 2. 理解代码： 这一步开始理解代码为什么在那里、它做了什么，以及它如何与数据连接。示例：意识到 mean() 用于计算均值，而 c(1, 2, 3) 用于创建向量；同时也要理解什么是向量。
  • 3. 编写代码： 这是学习的高阶阶段。经过练习后，你将能够编写自己的脚本和函数，用于作图、分析或自动化任务。示例：使用 plot(x, y) 创建图形，并根据需要调整参数。


注释

注释是程序中用于解释某段代码的内容。在 R 中，可以用 # 符号添加注释。
注释的作用包括：提高可读性、临时忽略某些代码，以及书写伪代码。


# Anything that starts with # is a comment and is not executed

变量

不同类型的值，例如字符、数字或逻辑值，都可以赋给变量


x <- 10 # The most common form of assignment
y = 20 # Also works

在 R 中，和几乎所有编程语言一样，变量名中不允许使用空格。如果你尝试这样写：
你可以使用下划线 _、点号 .，或 camelCase（驼峰式命名）来分隔变量名中的单词，例如：


patient_age <- 25
patient.age <- 25
PatientAge <- 25

换句话说，每次创建变量时，都要避免使用空格，并使用合法字符。请注意，虽然下面这些写法各自都是可以接受的，但每一种写法都会创建不同的变量。


R 会区分一切细节

人与人交流时，我们能够理解小错误、语言差异和拼写错误。但 R 不是这样。


在 R 中，age、Age、ages 和 Ages 是完全不同的名称。这是因为 R 是区分大小写的语言。


同一个工作空间中的每个变量都必须是唯一的；也就是说，每当我用不同方式书写名称时，就会创建一个新的对象。这一点很重要，因为它可以避免混淆，并确保你清楚自己正在使用哪个变量。
因此，请创建有意义、容易记住，并且对你来说足够清晰可区分的变量名。

变量命名规则:

  • 变量名可以由字母、数字、点号和下划线组成。
  • 变量名应以字母开头，不能以数字开头。
  • 如果变量名以点号开头，点号后面不能直接跟数字。
  • R 和其他编程语言一样区分大小写。因此 age、Age 和 AGE 是不同变量。
  • 避免使用重音符号和特殊字符。
  • 命名要具有描述性，但不要过度冗长。
  • 写法应简单，并保持统一格式。变量名越清楚，之后越容易复用。
  • if_it_is_too_long_it_is_bad_to_reuse

是什么意思？

这个箭头用于把一个值赋给某个对象。可以把它理解为：“把这个值放到这个小盒子里。” 或者说：“现在 x 的值是 10，y 的值是 20。"


<- 是 R 社区中传统且最常用的赋值方式，尤其在统计学和数据科学中很常见。它像是一种语言传统：很多人认为箭头清楚地表示值从哪里来、被放到哪里去。


在键盘上输入 <- 时，先输入 <，再输入 -，R 会自动把它理解为赋值。

数据和数据类型

在 R 中，数据通常组织为表格（data frame），类似 Excel 电子表格。每一列代表一个变量（如年龄、姓名、身高等），每一行代表一个观测对象（如一个人、一只动物、一次实验等）。
你可以手动创建数据：



# There are several data types in R, but the most common are:
# Numbers
x <- 10.5 # Decimal numbers

# Integer
y <- 5L # Integer numbers

# Text (we call them "strings")
name <- "my name is:" # Text in quotes (fill in your name)

# Logical (boolean)
true <- TRUE # True
false <- FALSE # False

# Vectors
ages <- c(25, 30, 35) # Vector of numbers

c() 是一个函数，含义是 combine 或 concatenate，用于创建向量。


向量中的所有元素必须属于同一种类型。如果不使用 c()，R 无法理解你想创建一个向量，并会报错。使用 c() 时，R 会理解你要把这些值合并成一个对象，也就是形成一个向量。


只要你想创建包含多个值的向量，无论这些值是数字、文本还是逻辑值，都可以使用 c()。

Factor

factor 用于表示分类变量，例如“性别”“婚姻状态”或“是/否回答”。在底层，R 会把这些值当作带有名称的数值层级来处理。 


sex <- factor(c("F", "M", "F"))

R 会把它理解为一个包含两个水平（level）的变量：F 和 M

factor 在统计分析中非常重要，因为它会把类别当作明确的不同水平，而不是普通文本。

    什么是函数？

    函数是已经写好的命令，可以替你完成某项操作。前面你已经见过一些函数。函数通常遵循下面的结构：

    
function_name(argument 1, argument 2, ...)                    
                
    
#Example:
mean(c(1, 2, 3, 4))
  • mean 是函数名称。
  • c(1, 2, 3, 4) 是参数，也就是一个数字数组。
  • 函数可以节省时间，并帮助组织你要完成的任务。R 中有数百个函数；你甚至可以创建自己的函数，也可以使用别人写好的函数。

    • 什么是函数参数?

    在 R 中使用函数时，我们需要向函数传入必要信息，这样它才知道该做什么。这些信息称为参数。可以把参数想象成一次实验中的具体步骤。

    
round(3.14159, digits = 2)

    绘制数值型数据

    R 中有多种创建图形的方式，但本节重点介绍 ggplot2 包。它是一个强大而优雅的数据可视化工具，基于所谓的“图形语法”（grammar of graphics）。这种语法允许你用结构化、直观的方式构建图形，就像在书写有意义的句子一样。


    图形语法是一组规则，用来定义如何以逻辑化、标准化的方式构建可视化。它最大的优势在于：只要掌握同一种结构，就可以创建多种不同类型的图形，而不需要为每一种图形分别记忆不同参数。


    ggplot2 的突出特点是让你能完全控制图形：坐标轴、颜色、可视化类型、标题、图例等每一部分都可以由你决定。所有内容都可以通过图层逐步添加和调整。这让图形更个性化，也更具信息量。


    图形语法有三个主要组成部分：


  • Data: 数据集中的观测。
  • Aesthetics: 把数据映射到视觉属性，例如坐标轴和几何对象大小。
  • Geometries: 几何对象，例如线条，代表图中实际看到的内容。
